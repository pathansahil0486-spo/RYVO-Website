## 🌐 Multi-Page Structure
The website features 8 dedicated HTML pages, each with a persistent sticky top navbar and responsive mobile drawer:
1. `index.html`: Corporate Home portal with hero banner, live metric counters, featured services, product previews, client testimonials, and tech stack marquee.
2. `about.html`: Company story, Mission, Vision, 6 Core Values, and the 5-stage Engineering Lifecycle.
3. `leadership.html`: Executive profiles for Sachin Rathore, Roshani, and Sahil Pathan with role breakdowns, core focus areas, and verified leadership credentials.
4. `services.html`: All 7 enterprise service offerings detailed, prominently featuring Billing Software Development (POS), Mobile Apps, Web Development, and IT Consulting.
5. `products.html`: Flagship software solutions (Q-Bill Pro Enterprise, Q-Commerce Engine, Q-Track Telematics, Q-Desk Omnichannel) with feature matrices and live demo links.
6. `portfolio.html`: Filterable case studies with interactive details modal.
7. `estimator.html`: Dynamic project cost and timeline calculator that seamlessly transfers selections into the inquiry form.
8. `contact.html`: Contact directory, direct founder dispatch to `qcomsoft@gmail.com` and WhatsApp, and interactive FAQ accordion.

## 🎨 Design & UI Architecture
- **Unified Corporate Theme**: High-contrast, clean, bright corporate tech style with sharp typography (`Inter` and `Plus Jakarta Sans`).
- **Sticky Top Navbar**: Rock-solid sticky navigation (`position: sticky; top: 0`) that remains pinned at the top on desktop and mobile when scrolling.
- **Mobile-First Responsiveness**: Handcrafted and tested down to **320px** screen widths (iPhone SE / compact Android devices) with zero horizontal overflow, 44px+ touch targets, and slide-out navigation.

## ⚡ Instant Deployment Guide

### Option 1: Deploy to Vercel (< 1 Minute)
1. Push this folder to GitHub:
   ```bash
   git add .
   git commit -m "Deploy Q COM Software Solutions multi-page website"
   git push origin main
   ```
2. In [vercel.com](https://vercel.com), click **Add New Project** and import the repo.
3. Click **Deploy**. Vercel will instantly serve the site using `vercel.json` with clean URLs and security headers.

### Option 2: Deploy to Netlify (Drag & Drop in 30 Seconds)
1. Visit [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`Company Website`).
3. Your site is immediately live with HTTPS and custom domain options.
