## ⚡ Instant Deployment Guide

### Option 1: Deploy to Vercel (Recommended, < 1 Minute)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Q COM Software Solutions website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/qcom-website.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository. Vercel automatically detects the static HTML project and `vercel.json`.
4. Click **Deploy**. Your site is live on your `.vercel.app` URL with SSL enabled!

*Alternative CLI Deployment:*
```bash
npm i -g vercel
vercel
```

---

### Option 2: Deploy to Netlify (Drag & Drop, 30 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`Company Website`) into the browser.
3. Your site is instantly live with custom domain support and SSL!
